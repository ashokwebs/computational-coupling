# Open Source Repository Report: vandijklab/brainlm

**Project Name:** Generative fMRI Foundation Model  
**GitHub URL:** `https://github.com/vandijklab/brainlm`  

---

## 🚀 Overview & Role in Program
Developed by David van Dijk's lab at Yale. Trained on 6,700 hours of fMRI across 424 brain parcels. Used for spatial semantic feature extraction.

## 🛠️ Installation & Recommended Usage
```bash
git clone https://github.com/vandijklab/brainlm.git
pip install -e .
```
Used in our research pipeline to extract latent neural tokens, solve FUGW optimal transport alignment matrices, or evaluate benchmark transfer entropy models.
