# Open Source Repository Report: 935963004/LaBraM

**Project Name:** Large Brain Model for Learning Generic EEG Representations  
**GitHub URL:** `https://github.com/935963004/LaBraM`  

---

## 🚀 Overview & Role in Program
Developed by Bao-Liang Lu's group at SJTU. Pre-trained on 2,500 hours of clinical EEG using VQ-NSP. Acts as our temporal latent codec for neural state spaces.

## 🛠️ Installation & Recommended Usage
```bash
git clone https://github.com/935963004/LaBraM.git
pip install -e .
```
Used in our research pipeline to extract latent neural tokens, solve FUGW optimal transport alignment matrices, or evaluate benchmark transfer entropy models.
