# Research Paper Report: A Reduced-Dimension fMRI Shared Response Model

**Authors:** Po-Hsuan Chen, James Haxby, Peter Ramadge  
**Publication Year:** 2015  
**Venue:** *Advances in Neural Information Processing Systems (NeurIPS 2015)*  

---

## 📌 Summary
Introduced Shared Response Model (SRM) factorizing multi-subject fMRI into orthogonal shared response matrices $S$. Predecessor to non-linear FUGW optimal transport alignment.
